# Техническая спецификация проекта "МедиаПульс"

## 1. Обзор проекта
**МедиаПульс** — это платформа для комплексного управления SMM, включающая аналитику, планирование контента и систему модерации постов от волонтеров.

## 2. Технологический стек
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Charts:** Recharts или Chart.js
- **Routing:** React Router DOM

## 3. Структура страниц

### 3.1. Landing Page (Главная)
- **Hero section:** Заголовок, подзаголовок, призыв к действию (CTA).
- **Features:** Карточки с описанием ключевых функций (Аналитика, Календарь, Модерация).
- **Stats Preview:** Демонстрация возможностей дашборда.
- **Footer:** Ссылки и контакты.

### 3.2. Авторизация и Регистрация
- **Login:** Email, пароль, "Забыли пароль?", вход через соцсети.
- **Register:** Имя, Email, пароль, подтверждение пароля, выбор роли (Менеджер/Волонтер).

### 3.3. Dashboard (Панель управления)
- **Общая статистика:** Виджеты (Посты, Средний охват, ERR - Reactions/Reach * 100%).
- **График динамики:** Линейный график охватов по дням/часам.
- **Топ-5 постов:** Список лучших публикаций с превью и метриками.
- **Экспорт:** Кнопки выгрузки в PDF/Excel.

### 3.4. Календарь контента
- **Сетка:** Отображение постов по дням и часам.
- **Управление:** Добавление запланированных постов, редактирование существующих.

### 3.5. Детальная аналитика
- **Таблица:** Список всех постов с возможностью фильтрации и сортировки по всем метрикам.
- **Сравнение:** Инструменты сопоставления эффективности разных площадок.

### 3.6. Управление контентом и Каналами
- **Подключения:** Список привязанных аккаунтов соцсетей.
- **OAuth:** Интеграция новых каналов.
- **Тест:** Функция отправки тестового поста.

### 3.7. Модерация (Для менеджеров)
- **Список заявок:** Таблица предложенных постов от волонтеров.
- **Редактор:** Возможность правки текста и медиа волонтера.
- **Решение:** Кнопки "Принять" или "Отклонить" (с выбором причины из шаблонов).

## 4. Дизайн-система (Tailwind)
- **Цвета:** Основной (Primary Blue), Акцентный (Indigo), Опасность (Red), Успех (Green).
- **Компоненты:** Единый стиль кнопок, карточек и полей ввода.
- **Адаптивность:** Полная поддержка Desktop, Tablet и Mobile.
