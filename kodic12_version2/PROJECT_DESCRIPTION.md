# Описание проекта MediaPulse

## Обзор
**MediaPulse** — это веб-приложение, построенное на стеке React + Vite. Судя по структуре страниц и зависимостям, проект представляет собой аналитическую платформу или панель управления (dashboard) с визуализацией данных.

## Технологический стек
- **Frontend-фреймворк:** React 18
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS (с PostCSS и Autoprefixer)
- **Маршрутизация:** React Router DOM v6
- **Иконки:** Lucide React
- **Графики и визуализация:** Recharts

## Структура проекта
- `src/main.jsx` — точка входа в приложение.
- `src/index.css` — глобальные стили и директивы Tailwind.
- `src/pages/` — основные компоненты страниц:
    - `LandingPage.jsx` — главная (посадочная) страница.
    - `LoginPage.jsx` — страница авторизации.
    - `RegisterPage.jsx` — страница регистрации.
    - `DashboardPage.jsx` — основная рабочая область с аналитикой.

## Конфигурационные файлы
- `package.json` — зависимости и скрипты проекта.
- `tailwind.config.js` — настройки темы и путей Tailwind.
- `vite.config.js` — конфигурация сборщика Vite.
- `postcss.config.js` — настройки обработки CSS.
- `specification.md` / `plan.md` — проектная документация и планы разработки.

## Как запустить
1. Установите зависимости: `npm install`
2. Запустите режим разработки: `npm run dev`
3. Сборка проекта: `npm run build`
