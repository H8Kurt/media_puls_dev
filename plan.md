Название проекта: МедиаПульс
Видиние:
1. Dashboard: общая страница с информационными блоками
1.1. Общая статистика (количество постов, средний охват, вовлечённость - ERR формула = количество реакций/охват*100% )
1.2. Динамика охватов по дням, часам (график)
1.3. Топ-5 постов по вовлечённости с превью
1.4. Экспорт в PDF/EXCEL

2. Календарь
2.1. Визуальное отображение по дням/часам
2.2. Возможность добавить мероприятие с заплонированным временем для постинга, возможность редактировать посты до выкладки

3. Детальная аналитика
3.1. Таблица со всеми постами и метрики сортировки, фильтров
3.2. Сравнение охватов между площадками

4. Управление контентом
4.1. Список подключённых соцсетей
4.2. Добавление нового канала через авторизацию (QAuth)
4.3. Тестовая отправка для проверки подключения

5. Модерация постов
5.1. Вкладка с календарём по датам
5.2. Возможность нажать на любой день и посмотреть в таблице все предложенные посты от волонтёров
5.3. Возможность вручную изменить содержимое постов волонтёров 
5.4. Возможность принять или отклонить пост с уведомлением волонтёра.
5.4.1. При отклонении шаблоны отказа (Неподходящая тема, неподходящая фотография и т.д.)
